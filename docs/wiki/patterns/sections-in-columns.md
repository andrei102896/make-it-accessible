# Sections in columns

**Seen in:** 16 of 19 US menus print sections side by side (Carmine's 3 columns in red frames, Almond and Pastabilities 4, Sarge's 3–4); Gargiulo's mixes full-width rows with two-column groups; Prohibition Post flows one article across 4 columns.

**Rule (planned):** cluster by each list's x-range, not by heading centres (headings are left-aligned at varying widths or centred over several lists). A list wider than 60% is a full-width row; narrow lists with disjoint ranges form a grid group (≤ 4 columns) on desktop and stack on phones, in print order. A running article across columns is CSS multicol, the only place multicol is used.

**Measurement:** `columnsPerPage` in `wiki-facts.ts`.
