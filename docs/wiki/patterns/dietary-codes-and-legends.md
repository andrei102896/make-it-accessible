# Dietary codes and legends

**Seen in:** Moosewood (legend "(V) VEGAN … (GFO) GLUTEN FREE OPTION" plus a fish icon with no text, codes in parentheses after the price, "(GFO, )" where the icon was), Ridgway ("gf" before 19 dish names), Kendells (a leaf glyph from a symbol font read as "Veggie"), Carew (V, VE, GF, GFO after the name with a legend line).

**Today:** only "V Vegan" legend lines and codes trailing the name are recognised; Moosewood's codes render as a text line under the dish, the icon as a "Fish" line.

**Rule (planned):** legend entries in the "(V) VEGAN" form; codes on their own line, in parentheses, or before the name become tags beside the name (the code visible, the legend's word for screen readers); orphan commas dropped; an icon word read from the image shown as a tag.
