# Cases — what each PDF taught the engine

Every finding on a specific PDF enters here and leaves the engine better for every PDF after it (Andrei, 2026-10-19). A case is closed only when: the general principle it reveals is written; the fix is a mechanism with nothing keyed to that PDF; the PDF stays only as a regression test; a new kind of content error is also a defect in `eval/inject.ts`; the change is measured on the whole working set (no regressions) and judged on the verification set (`docs/EXECUTION_PLAN.md`).
